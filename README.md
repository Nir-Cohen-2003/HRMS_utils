# HRMS Utils

Polars-based utilities for high-resolution mass spectrometry data.

## User workflows

- [mzML → MS-DIAL → formula annotation](docs/tutorials/01-msdial-chromatogram-annotation.md)
- [Calibrate isotopic parameters](docs/how-to/calibrate-isotopic-parameters.md)
- [Canonical data structures and output schema](docs/reference/data-structures.md)

MS-DIAL is an external executable. Download it from the [official releases](https://github.com/systemsomicslab/MsdialWorkbench/releases)
and follow the documented MS-DIAL 5 metadata-CSV workflow before parsing its
compatible tabular output with HRMS Utils.
